MOEKETSI MOKOTEDI — CV PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted "moeketsi-cv-portfolio" folder in Visual Studio Code.
3. Install the "Live Server" extension in VS Code if you have not already.
4. Right-click index.html and choose "Open with Live Server".
5. Use the navigation buttons to open the separate pages.

DOWNLOAD CV BUTTON
The original PDF is stored at downloads/Moeketsi-Mokotedi-CV.pdf.
The Download CV links point to this file using a relative path, so keep the
downloads folder and PDF in place when moving or publishing the website.

PAGES
index.html       Home
about.html       About
skills.html      Skills
projects.html    Projects (contains clearly marked starter examples)
education.html   Education & Certifications
experience.html  Experience
contact.html     Contact

CUSTOMIZE
- Replace or edit any text to reflect your preferred wording.
- The projects page includes placeholders/examples; edit them to match real work.
- For public hosting, upload the whole folder so the downloads folder is included.
- The contact page uses your email and phone from the supplied CV and displays
  Kroonstad, South Africa rather than publishing your full street address.

PROFILE PHOTO
The full original photo is stored at images/moeketsi-networking.jpg and appears on the Home and About pages. Keep the images folder when moving or publishing the website.
